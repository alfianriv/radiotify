# AI DJ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Radio-style DJ interstitials between songs: LLM-written Indonesian script (OpenRouter free model) → edge-tts voice → played as a micro-track in the deterministic timeline.

**Architecture:** `DjService` generates a clip (script + MP3 in `audio_cache/dj-<ts>.mp3`) asynchronously while the next track is being prepared (≥20s window). At transition time, if a clip is ready and the per-N-tracks counter is due, the engine plays the clip as its own track (`is_dj` meta, exempt from the 60s validity rule and from history), with the real next track kept preloaded in state so the following transition proceeds normally. Every failure path (no API key, 429, TTS error, timeout) degrades to a normal transition.

**Tech Stack:** OpenRouter chat completions (`DJ_MODEL`, default free Llama 3.3 70B), `edge-tts` (id-ID neural voices, free, keyless), ffprobe for clip duration, existing AudioCache + HlsLiveWorker.

**Config (env):** `OPENROUTER_API_KEY` (empty = feature off), `DJ_MODEL`, `DJ_VOICE` (`id-ID-ArdiNeural`), `DJ_EVERY_N_TRACKS` (4), `DJ_ENABLED` (true).
